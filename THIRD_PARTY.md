# Third-party data and assets

## Wikidata

- Data: names, coordinates, descriptions, links and selected structured facts
- License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
- Source links are retained on every applicable record.

## Wikimedia Commons

- Data: image previews and attribution metadata
- License: varies by file (for example CC0, CC BY, or CC BY-SA)
- Every image record retains its author, license name, license URL, and source page. The source page is authoritative if snapshot metadata has changed.

## TeamTest57/Kofun360

- Data: coordinates and 360-degree photographs
- License: [CC0 1.0](https://github.com/TeamTest57/Kofun360/blob/main/LICENSE)
- This project stores lightweight WebP previews and loads an original panorama only when a visitor explicitly starts the 360-degree viewer.

## OpenStreetMap

- Data and map tiles: © OpenStreetMap contributors
- Data license: [Open Data Commons Open Database License](https://www.openstreetmap.org/copyright)
- Visible attribution is shown in the map. This project does not prefetch or bulk-download map tiles.
